# Wi-Fi Password Extractor

A simple Python script to extract Wi-Fi passwords from a Windows system.

## Description

This script uses the `netsh` command to extract Wi-Fi profiles and their corresponding passwords from a Windows system. It requires administrative privileges to run.

## Requirements

* Python 3.x
* Windows operating system
* Administrative privileges

## Usage

1. Clone the repository: `git clone https://github.com/your-username/wifi-password-extractor.git`
2. Navigate to the repository directory: `cd wifi-password-extractor`
3. Run the script: `python wifi_password_extractor.py`

The script will extract the Wi-Fi passwords and display them in a formatted output.
Profile_Name | Password

## Example Output

MyHomeNetwork |	mysecretpassword
OfficeNetwork | anotherpassword
